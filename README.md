# MediCare – Medical Care Landing Page

A responsive medical landing page built with React and Vite based on the design provided for the frontend assessment.

The project includes responsive layouts, dark/light mode, animations, reusable components, and a few interactive features.

## Features

- Responsive design for mobile, tablet, and desktop
- Reusable React components
- Smooth scrolling
- Framer Motion animations and scroll effects
- Dark and light mode with localStorage support
- Mobile navigation menu
- Interactive consultant/doctor cards
- Category filtering
- Appointment booking modal
- Ai generated doctors images
- Live chat demo
- Hover effects
- Accessibility support
- SEO meta tags and structured data

## Tech Stack

- React 18
- Vite
- CSS Modules
- Framer Motion
- Lucide React
- Plus Jakarta Sans
